Kedudukan Garis Terhadap Lingkaran

Setelah modul ini selesai, kamu akan bisa:

  • Memahami tiga kemungkinan kedudukan garis terhadap lingkaran: memotong, menyinggung, atau tidak berpotongan.
  • Menghitung jarak dari pusat lingkaran ke sebuah garis.
  • Menentukan kedudukan garis hanya dengan membandingkan jarak (d) dan jari-jari (r).
  • Mencari nilai parameter supaya sebuah garis tepat menyinggung lingkaran tertentu.

01

Pernahkah Kamu Berpikir?

Bayangkan kamu melempar tali lurus ke arah kolam renang yang bentuknya bundar.

Kadang talinya menembus kolam, sampai ujung ke ujung — dua sisi kolam tersentuh sekaligus.

Kadang talinya cuma menyentuh tepi kolam di satu titik saja, lalu lurus pergi lagi.

Dan kadang talinya meleset total, lewat di luar kolam tanpa menyentuh sama sekali.

Kolamnya sama, talinya sama panjang dan sama lurus. Yang beda cuma satu hal: posisi tali itu terhadap pusat kolam. Menurutmu, bagaimana caranya kita tahu dari rumus, tanpa perlu menggambar dulu?

02

Penjelasan Sederhana

Ternyata untuk tahu kedudukan garis terhadap lingkaran, kita cuma perlu membandingkan dua angka: jarak dari pusat lingkaran ke garis (sebut saja d), dan jari-jari lingkaran (r).

Kalau d lebih kecil dari r, garisnya "menerobos" masuk sampai memotong lingkaran di dua titik.

Kalau d sama persis dengan r, garisnya cuma menyentuh lingkaran di satu titik — inilah yang disebut garis singgung.

Kalau d lebih besar dari r, garisnya meleset, sama sekali tidak menyentuh lingkaran.

Untuk menghitung d, kita pakai rumus jarak titik ke garis. Kalau garisnya Ax + By + C = 0 dan pusat lingkarannya (a, b), maka d = |A·a + B·b + C| / √(A² + B²). Setelah dapat d, tinggal dibandingkan dengan r.

03

Lihat Cara Kerjanya

Kita pakai contoh: garis g: 3x + 4y − 25 = 0, dan lingkaran pusat P(0, 0) dengan jari-jari r = 5. Tekan Next untuk lihat langkah demi langkah.

04

Coba Sendiri

Lingkarannya tetap di pusat O(0,0). Geser garis vertikal x = c dan ubah jari-jari r, lalu lihat kedudukannya berubah secara langsung.

Challenge

MUDAH

Soal 1

Lingkaran x² + y² = 25 (pusat O, jari-jari 5) dan garis x = 3. Hitung jarak pusat ke garis (d), lalu tentukan kedudukannya.

SEDANG

Soal 2

Garis 3x + 4y − 20 = 0 dan lingkaran (x − 1)² + (y − 2)² = 9 (pusat (1, 2), jari-jari 3). Hitung d (boleh 1 angka desimal), lalu tentukan kedudukannya.

SULIT

Soal 3

Garis x + y = c menyinggung lingkaran x² + y² = 18. Carilah nilai c, dengan syarat c bernilai positif.

06

Kesalahan yang Sering Terjadi

✕

Lupa tanda mutlak pada rumus jarak.

Hasil A·a + B·b + C kadang negatif. Padahal jarak selalu bernilai positif, jadi harus dimutlakkan dulu sebelum dibagi.

✕

Salah membagi penyebut.

Penyebutnya adalah √(A² + B²), bukan (A + B). Dua garis dengan koefisien berbeda tidak boleh disamakan cara membaginya.

✕

Lupa mengakar ruas kanan persamaan lingkaran.

Kalau persamaannya x² + y² = 25, jari-jarinya adalah √25 = 5, bukan 25. Salah di sini bikin salah menentukan kedudukan.

07

Ringkasan

  • 1Kedudukan garis terhadap lingkaran ditentukan dengan membandingkan jarak pusat ke garis (d) dan jari-jari (r).
  • 2Kalau d < r, garis memotong lingkaran di dua titik.
  • 3Kalau d = r, garis menyinggung lingkaran tepat di satu titik.
  • 4Kalau d > r, garis tidak menyentuh lingkaran sama sekali.
  • 5Rumus jarak pusat (a, b) ke garis Ax + By + C = 0 adalah d = |A·a + B·b + C| / √(A² + B²).
